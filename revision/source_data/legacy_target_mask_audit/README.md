# Legacy perturbation-target mask audit

This folder documents a fail-open perturbation-target masking path in the archived benchmark code.

- `legacy_target_mask_code_evidence.csv` records deterministic code checks.
- `legacy_target_mask_condition_audit.csv` audits each condition label against the legacy `+` parser.
- `legacy_target_mask_summary.csv` aggregates syntax and, where an exact public source H5AD is
  available, full-gene-universe matching.
- `legacy_target_mask_source_manifest.csv` identifies inspected inputs by file name and digest without
  exposing a local filesystem path.
- `legacy_target_mask_audit_report.md` states the result and its interpretation boundary.

The audit is generated by `SOURCE/scripts/audit_legacy_target_masks.py`. It does not infer a missing
HVG list or claim an exact affected fraction when the archived fold did not retain that evidence.

The Adamson source audit uses the exact public file named in the archived download script,
`AdamsonWeissman2016_GSM2406681_10X010.h5ad`, from the
[scPerturb Zenodo record](https://doi.org/10.5281/zenodo.10044268). Its MD5 digest in the manifest
matches the record (`2fa44ea61a8dd35742af618638ec65fc`). The H5AD itself is not redistributed.

The Norman audit analogously uses `NormanWeissman2019_filtered.h5ad` from the same record. Its
manifest MD5 matches the published digest (`c870e6967d91c017d9da827bab183cd6`). The exact-source
metadata establish a guaranteed fail-open lower bound of 27/50 archived Norman conditions; the
fold-specific HVG lists needed to resolve the other 23 were not retained.
