# Dataset control-label audit

This folder freezes the source-backed control contract for the exact Adamson and Norman H5AD files
used by the revised production protocol. It exists because the archived code silently substituted the
modal condition whenever no recognised control string was present.

- `dataset_control_contract.csv` is the machine-readable production contract.
- `dataset_control_label_counts.csv` records verified controls and fail-closed exclusions.
- `dataset_control_source_manifest.csv` identifies source artifacts by digest and URL.
- `dataset_matrix_count_provenance.csv` separates locally revalidated Adamson/Norman shapes from
  source-reported Replogle counts whose production matrices are not present.
- `dataset_control_audit_report.md` explains the decision and release gate.

The files are regenerated by `SOURCE/scripts/audit_dataset_controls.py`; no local filesystem path is
written to reader-facing evidence.
